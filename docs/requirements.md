# SkillBridge MVP Requirements

## User roles
- Student freelancer: creates profile and lists services.
- Client: discovers services and requests work.
- Admin: future moderation and reporting role.

## MVP functional requirements
1. Browse services and filter by category.
2. Search service title, freelancer and skills.
3. View service details.
4. Register/sign in in demo mode.
5. Publish a service.
6. Place a simulated order as a client.
7. View order history.
8. Persist demo state in browser localStorage.

## Non-functional requirements
- Responsive desktop and mobile UI.
- Validate required fields and positive prices.
- Keep payment in simulation mode.
- API health endpoint and REST API.
